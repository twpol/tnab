## CSS 1.0

**Standard:** [Cascading Style Sheets, level 1](https://www.w3.org/TR/CSS1/) (1996-12-17)

| Group          | Selector        | Supported |
| -------------- | --------------- | --------- |
| Basic          | Class           | ❓        |
| Basic          | ID              | ❓        |
| Basic          | Type            | ❓        |
| Combinator     | Descendant      | ❓        |
| Pseudo-class   | `:active`       | ❓        |
| Pseudo-class   | `:link`         | ❓        |
| Pseudo-class   | `:visited`      | ❓        |
| Pseudo-element | `:first-letter` | ❓        |
| Pseudo-element | `:first-line`   | ❓        |

| Property | Supported |
| -------- | --------- |
