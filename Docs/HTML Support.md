## HTML Tags

| Element                  | Support | Notes    |
| ------------------------ | ------- | -------- |
| `<title>`                | ❌      |
| `<nextid>`               | ❌      | Obsolete |
| `<a href>`               | ❌      |
| `<a name>`               | ❌      |
| `<a type>`               | ❌      |
| `<isindex>`              | ❌      |
| `<plaintext>`            | ❌      |
| `<listing>`              | ❌      |
| `<xmp>`                  | ❌      |
| `<p>`                    | ❌      |
| `<h1>`..`<h6>`           | ❌      |
| `<address>`              | ❌      |
| `<hp1>`..`<hp6>`         | ❌      | Obsolete |
| `<dl>` + `<dt>` + `<dd>` | ❌      |
| `<ul>` + `<li>`          | ❌      |
| `<menu>` + `<li>`        | ❌      |
| `<dir>` + `<li>`         | ❌      |
