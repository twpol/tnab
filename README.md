# TNAB (The Not As Bad web browser)

Command-line, graphical tools and libraries for loading, rendering, browsing websites.

## CLI

```
TNAB (The Not As Bad web browser) CLI

Usage:
  TNAB.Cli [action <URL> [...]] [...]

Actions:
  /print-dom            Print the HTML tree from the specified URLs
  /print-nodes          Print the HTML nodes from the specified URLs
  /print-tokens         Print the HTML tokens from the specified URLs

Arguments:
  <URL>                 URL to load
```
